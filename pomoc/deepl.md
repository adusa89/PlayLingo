# DeepL – lepší překlad (zdarma s vlastním klíčem)

Klíč se do televize **nepíše ovladačem** – zkopíruješ a vložíš ho jen v telefonu (Android i iPhone).

1. Televize (průvodce → krok Kvalita překladu, nebo ⚙ Nastavení) ukáže **čtvereček**. Naskenuj ho
   telefonem na **stejné Wi‑Fi** – otevře se stránka „PlayLingo · DeepL“.
2. **Účet DeepL** (jen poprvé): 👉 **[DeepL API Free](https://www.deepl.com/pro-api)** → Free API Key →
   registrace e-mailem a heslem (bez platební karty) → potvrď e-mail.
3. **Zkopíruj klíč:** 👉 **[Stránka s klíči](https://www.deepl.com/your-account/keys)** → u klíče tlačítko
   pro kopírování. Klíč končí na `:fx`.
4. Vrať se na kartu „PlayLingo · DeepL“, **podrž prst v políčku → Vložit** → **Odeslat do televize**.
5. Hotovo – televize klíč ověří a DeepL zapne.

Když odkazy nefungují, hledej **„DeepL API Free key“**.

Bezplatný účet má měsíční limit znaků (aplikace ukáže, kolik zbývá) – stačí na desítky hodin hraní.
Se zapnutým DeepL se rozpoznaný text titulků posílá do DeepL.

---
*English: scan the QR code on the TV with a phone on the same Wi‑Fi. Create a free
[DeepL API Free](https://www.deepl.com/pro-api) account, copy your key on the
[keys page](https://www.deepl.com/your-account/keys), go back to the “PlayLingo · DeepL” tab,
paste it and send it to the TV. Nothing is typed with the remote.*
