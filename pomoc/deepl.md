# DeepL – lepší překlad (zdarma s vlastním klíčem)

Klíč se do televize **nepíše ovladačem** – zkopíruješ a vložíš ho jen v telefonu (Android i iPhone).

> **Máš DeepL jen na překládání (DeepL Translator)?** Ten účet klíč nemá – tlačítko pro vytvoření klíče
> tě přesměruje zpátky do Translatoru. Pro PlayLingo si založ **nový účet pro API s jiným e-mailem**.

1. Televize (průvodce → krok Kvalita překladu, nebo ⚙ Nastavení) ukáže **čtvereček**. Naskenuj ho
   telefonem na **stejné Wi‑Fi** – otevře se stránka „PlayLingo · DeepL“.
2. **Účet DeepL** (jen poprvé): 👉 **[Registrace DeepL API – plán Developer](https://www.deepl.com/en/signup?cta=checkout&is_api=true&productId=api-developer)**
   → e-mail a heslo (bez platební karty) → potvrď e-mail.
   - Otevři to v prohlížeči, kde **nejsi přihlášený do DeepL** (jinak tě registrace přesměruje do
     Translatoru). Nejjednodušší je soukromá karta: iPhone – Safari → Panely → Soukromé;
     Android – Chrome → ⋮ → Nová anonymní karta.
   - Když registrace visí na **„Security check“**, vypni VPN nebo blokování reklam (na iPhonu i Soukromý
     přenos iCloud), případně zkus jiný prohlížeč nebo mobilní data.
3. **Zkopíruj klíč:** po přihlášení je klíč na úvodní stránce účtu (tlačítko **Copy key**), jinak
   👉 **[Stránka s klíči](https://www.deepl.com/your-account/keys)** → **Create key** → tlačítko pro
   kopírování. Klíč končí na `:fx`.
4. Vrať se na kartu „PlayLingo · DeepL“, **podrž prst v políčku → Vložit** → **Odeslat do televize**.
5. Hotovo – televize klíč ověří a DeepL zapne.

Když odkazy nefungují, otevři **deepl.com → Pricing → API → Developer → Sign up for free**.

Bezplatný plán Developer má limit znaků zdarma (aplikace ukáže, kolik zbývá) – stačí na desítky hodin hraní.
Se zapnutým DeepL se rozpoznaný text titulků posílá do DeepL.

---
*English: scan the QR code on the TV with a phone on the same Wi‑Fi. Create a free
[DeepL API account (Developer plan)](https://www.deepl.com/en/signup?cta=checkout&is_api=true&productId=api-developer)
– a DeepL Translator account has no API key, so use a new account with a different e-mail and sign up
in a browser where you are not signed in to DeepL (e.g. a private tab). Copy your key on the
[keys page](https://www.deepl.com/your-account/keys) (“Create key” if there is none), go back to the
“PlayLingo · DeepL” tab, paste it and send it to the TV. Nothing is typed with the remote.*
